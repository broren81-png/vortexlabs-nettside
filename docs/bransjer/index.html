Bransjer

Løsninger tilpasset bransjen din

Hver bransje har sine egne behov. Her ser du hva vi kan lage for din. Vi viser bare til prosjekter vi faktisk har gjort, og forteller ærlig når vi ikke har levert til en bransje før.

Bransjer vi lager løsninger for

Transportfirmaer

Nettside for transportfirma med priskalkulator, bestillingsskjema og sjåførportal. Vi driver selv biltransporttjenesten HentBilen og kjenner bransjen.

Les mer →

Håndverkere

Nettside for håndverkere som viser fagfeltet, tidligere arbeid og tar imot forespørsler. Fra 4 990 kr eks. mva. Gratis designforslag.

Les mer →

Bilverksteder

Nettside for bilverksted med timebestilling for service, EU-kontroll og dekkskift. Mobiltilpasset og enkel å bruke. Fastpris og gratis designforslag.

Les mer →

Bygg og anlegg

Nettside for bygg- og anleggsfirma som viser prosjekter og maskinpark, og digitale verktøy for oppdrag, mannskap og dokumentasjon.

Les mer →

Renholdsbedrifter

Nettside for renholdsbedrift med prisestimat for vask, bestilling av faste avtaler og oversikt over oppdrag. Fra 4 990 kr eks. mva.

Les mer →

Enkeltpersonforetak

Rimelig nettside for enkeltpersonforetak fra 4 990 kr eks. mva. Med det loven krever av opplysninger, kontaktskjema og hjelp med domene.

Les mer →

Frisører

Nettside for frisørsalong med timebestilling, prisliste og behandlinger. Pent, mobiltilpasset design som passer salongen. Fastpris før oppstart.

Les mer →

Restauranter

Nettside for restaurant og kafé med meny, allergener, åpningstider og bordbestilling. Rask på mobil, der gjestene leter. Fastpris og gratis designforslag.

Les mer →

Treningssentre

Nettside for treningssenter og PT med timeplan, påmelding til timer, medlemskap og app. Skreddersydd og mobiltilpasset. Fastpris før oppstart.

Les mer →

Lag og foreninger

Nettside for idrettslag, velforeninger og andre foreninger, med aktiviteter, nyheter, kontaktpersoner og innmelding. Rimelig og enkel å oppdatere.

Les mer →

Campingplasser

Nettside for campingplass med booking av plasser og hytter, fasiliteter, priser og flere språk for turister. Vi utvikler selv kartappen Northcast for camping og tur.

Les mer →

Småbedrifter

Nettsider, apper og bedriftssystemer for norske småbedrifter, uansett bransje.
