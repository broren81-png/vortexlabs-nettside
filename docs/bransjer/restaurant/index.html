Menyen som PDF

Allergener

Gjester med allergier vil vite hva rettene inneholder før de kommer.

Bordbestilling på telefon

Telefonen ringer midt i rushet.

Hvorfor

En nettside som selger maten

Menyen som en vanlig nettside med bilder er lett å lese på mobilen, og Google kan lese den. Allergener kan merkes per rett, så gjestene finner svaret selv.

Bordbestilling på nettsiden tar imot reservasjoner også når restauranten er stengt, og gir deg oversikt over kvelden.
